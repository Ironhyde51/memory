# Memory

SCSS-Starter mit 7-1-Struktur.

## Befehle

```powershell
npm install
npm run build
npm run watch
```

## Struktur

```text
scss/
  abstract/
  base/
  components/
  layout/
  pages/
  themes/
  vendor/
  main.scss
```

`scss/main.scss` ist die zentrale Datei. Die Unterordner sammeln ihre Dateien ueber eigene `_main.scss`-Dateien.
